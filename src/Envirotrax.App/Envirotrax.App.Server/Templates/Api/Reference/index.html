About the Envirotrax API

The Envirotrax API is a HTTP based API used to retrieve database records from the Envirotrax database. Clients will post application/x-www-form-urlencoded content to the API and will then receive a XML response from the server. The API is located at:

/api/v1/run

The HTTPS secured protocol must be used when making an API request.

Getting Started

Contact the Envirotrax administrator at administrator@envirotrax.com to be setup with an API account. The administrator will need the following information:

  • Envirotrax Water Supplier Name or ID
  • Contact Name
  • Contact Phone Number
  • Contact Email Address
  • API User ID (Email Address)
  • IP Address of the client machine making API requests

Once the Envirotrax administrator has setup your API account, you will receive an API Key and your client IP Address will be allowed through the firewall. You can then setup your HTTP client to send API requests.

Sending and Receiving Records

The API accepts the SELECT request type. This request type is comparable to its SQL counterpart: SELECT returns records.

At the heart of the SELECT request is the XML recordset <Recordset>:

  • The SELECT request will return a <Recordset> from the API
