API Responses

The API always answers with HTTP status 200. All API responses use <EnvirotraxApiResponse> as the root XML node, containing:

  • <ApiVersion>
  • <ServerName>
  • <ResponseUtcDate>
  • <ResponseStatus> – OK or ERROR

ERROR Response Status

Error responses include an <Errors> element with an <Error> element containing <ErrorNumber>, <ErrorType> and <ErrorMessage>. 

<?xml version="1.0" encoding="utf-8"?>
<EnvirotraxApiResponse>
  <ApiVersion>24.4.30.0</ApiVersion>
  <ServerName>IO API 1</ServerName>
  <ResponseUtcDate>9/28/2026 2:30:00 PM</ResponseUtcDate>
  <ResponseStatus>ERROR</ResponseStatus>
  <Errors>
    <Error>
      <ErrorNumber>201</ErrorNumber>
      <ErrorType>AuthorizationFailed</ErrorType>
      <ErrorMessage>Authorization Failed:  Invalid API credentials.</ErrorMessage>
    </Error>
  </Errors>
</EnvirotraxApiResponse>

OK Response Status - SELECT

A successful SELECT response includes <RequestSqlParameters> with TableName, SelectFields, SelectCriteria (including the water supplier restriction of the API account) and SelectOrder, plus <Recordset> containing <RecordCount> and a <Record> element per record. A field without a value is returned as an empty element, bit fields as True or False, and dates in the M/d/yyyy h:mm:ss tt format. 

<?xml version="1.0" encoding="utf-8"?>
<EnvirotraxApiResponse>
  <ApiVersion>24.4.30.0</ApiVersion>
  <ServerName>IO API 1</ServerName>
  <ResponseUtcDate>9/28/2026 2:30:00 PM</ResponseUtcDate>
  <ResponseStatus>OK</ResponseStatus>
  <RequestSqlParameters>
    <TableName>BackflowTests</TableName>
    <SelectFields>ID, SiteID, TestDate, TestResult, PropertyCity</SelectFields>
    <SelectCriteria>
      <WaterSupplierID>WaterSupplierID = 1234</WaterSupplierID>
      <LastModifiedDate>LastModifiedDate &lt; 9/1/2026 12:00:00 AM</LastModifiedDate>
    </SelectCriteria>
    <SelectOrder>
      <OrderBy>ID</OrderBy>
      <OrderByDirection>ASC</OrderByDirection>
    </SelectOrder>
  </RequestSqlParameters>
  <Recordset>
    <RecordCount>2</RecordCount>
    <Record>
      <Test.ID>500123</Test.ID>
      <Test.SiteID>88001</Test.SiteID>
      <Test.TestDate>8/14/2026 12:00:00 AM</Test.TestDate>
      <Test.TestResult>1</Test.TestResult>
      <Site.PropertyCity>Austin</Site.PropertyCity>
    </Record>
    <Record>
      <Test.ID>500124</Test.ID>
      <Test.SiteID>88002</Test.SiteID>
      <Test.TestDate>8/20/2026 12:00:00 AM</Test.TestDate>
      <Test.TestResult>2</Test.TestResult>
      <Site.PropertyCity>Round Rock</Site.PropertyCity>
    </Record>
  </Recordset>
</EnvirotraxApiResponse>

For a master water supplier account the restriction is echoed as <MasterWaterSupplierID>.
