SELECT Request

Submit the request as an HTTP POST with application/x-www-form-urlencoded content to /api/v1/run. The response is returned as text/xml.

Required Request Parameters

Parameter Acceptable Values
UserID [Your API User ID]
ApiKey [Your API Key]
RequestType SELECT
TableName Sites, BackflowTests
SelectFields Comma-separated list of field names, see Tables & Field Names. Field names are case-sensitive and are returned in the order listed. Example: ID, CreationDate, PropertyType, PropertyBusinessName, PropertyStreetNumber, PropertyStreetName, PropertyNumber, PropertyCity, PropertyState, PropertyZIP
Relational data. Sites and backflow tests are relational and joined by the SiteID. When BackflowTests recordset data is returned, field names will be prefixed with table origin: <Test.ID>123456</Test.ID>, <Site.PropertyCity>Austin</Site.PropertyCity>. Field names in a Sites recordset are not prefixed.

Query Criteria

At least one criterion must be specified; a request without criteria returns error 315. When several criteria are sent, a record must match all of them. Parameters that are not criteria of the requested table are ignored. Date values use the M/d/yyyy or M/d/yyyy h:mm:ss tt format, for example 9/28/2026 or 9/28/2026 2:30:00 PM.
