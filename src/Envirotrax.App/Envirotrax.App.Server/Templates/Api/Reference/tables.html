Database Tables and Allowable Fields

Your API account has access to the following database tables and fields. All of the fields listed can be returned by a SELECT [RequestType] by adding them to the [SelectFields] parameter.

Fields shown in green are Site table fields INNER JOINED with the report's fields. In a BackflowTests recordset they are returned with the Site. prefix, all other fields with the Test. prefix.
